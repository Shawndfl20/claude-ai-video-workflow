# 買美股零手續費，怎麼反而花更多？ · 繁中 Shorts

豎屏 1080×1920，22 句，配音後 86.8 秒。導流到長影片 [複委託 vs 海外券商](https://www.youtube.com/watch?v=MsbrNLv3h5s)（[風格 B 街機](../2026-10-us-broker-arcade/)）。

**主線：** 零手續費只免了買股票的錢；把錢匯過去還有「機票錢」，匯得越少、越頻繁，越不划算。

## 配音

MiniMax API（AIML，`speech-2.8-hd`、`Wise_Woman`、happy、語速 1.2），與長影片同一個聲音。用戶試過網頁版「錢的真相-女1」，生成結果偏離選定音色，改回 API。22 句、426 字，花費 US$0.0554；之後只改 `hold` 不重配。

讀音核對：本機缺 `sherpa_onnx`，自動核對沒有跑；多音字「還」（還是／還在／還沒／還有）、數字「一萬／十萬／百分之一」需用戶帶聲確認。

## 檢查

保留的警告：`text-dense`（第 4、6、7、9、11、12、14 句，11–18 字）：NEW WORD 卡（術語＋白話）、銀行／美國券商標籤和 HP 條的數字，都是指認物件和標數據，不是複述字幕。
